# Accessibility

> Historical note: this planning or decision doc is retained for reference only and is not authoritative for new work. Current authority lives in AGENTS.md, SRS, Acceptance Criteria, and the canonical docs named in docs/00-overview/authoritative-doc-map.md.


**Purpose:** Ensure the app is usable for more people and avoids common UI pitfalls.

## Checklist
- [ ] Keyboard navigation works for all major flows
- [ ] Focus order is logical
- [ ] Visible focus indicators
- [ ] Minimum contrast ratios (or supports High Contrast mode)
- [ ] Text scaling doesn’t break layout
- [ ] Clear error messages (not color-only)
